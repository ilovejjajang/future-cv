## 자기소개 (희망 직무: AI 응용 소프트웨어 개발자)
"날것의 데이터를 정제해 실제 돌아가는 결과물로 만드는 개발자"

수업에서 다루던 정제된 데이터와 달리, 실제 프로젝트에서 마주한 데이터는 엉망이었습니다. 에브리타임 강의평 3년 치를 크롤링해 KoBERT 모델에 넣었을 때, 학생들의 은어와 띄어쓰기 오류 때문에 모델이 제대로 작동하지 않는 것을 확인했습니다. 결국 데이터를 직접 까보며 전처리 코드를 짜서 정제한 후에야 유의미한 키워드를 뽑아낼 수 있었습니다.
쏘카 인턴십에서 대용량 로그 데이터를 다룰 때도 느꼈지만, AI 모델이 제대로 돌아가려면 결국 지저분한 현실 데이터를 끈기 있게 가공하는 과정이 필수적이라는 것을 배웠습니다. 거창한 모델 연구보다는, 이런 노이즈 낀 데이터를 쓸모 있게 만들고 사람들이 직접 써볼 수 있는 프로덕트로 구현해 내는 개발자가 되고 싶습니다.

## 프로젝트 경험
- **'에브리타임' 강의평 기반 광운대 맞춤형 교양 추천 챗봇 개발** (2026.09 - 2026.12)
  - **문제 인식:** 수강신청 기간마다 학생들이 수많은 텍스트 강의평을 일일이 읽고 분석해야 하는 불편함 발견
  - **해결 과정:** 교내 커뮤니티(에브리타임)의 과거 3년 치 교양 과목 강의평 데이터를 크롤링. 자연어 처리(NLP) 모델을 활용해 '팀플 유무', '과제량', '학점 비율' 등의 핵심 키워드와 긍/부정 감성을 추출하여 맞춤형 추천 모델 구축
  - **사용 기술:** Python, KoBERT(자연어 처리), BeautifulSoup(데이터 수집), Streamlit(웹 대시보드 배포)
