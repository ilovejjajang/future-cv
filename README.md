## 🎯 자기소개 (희망 직무: 주니어 데이터 사이언티스트)
**"데이터로 문제를 풀지만, 결국 사람이 쓰는 서비스를 만듭니다."**

데이터 분석은 복잡한 수식을 푸는 것이 아니라, 결국 '왜 이런 현상이 일어났는가'에 대한 질문에 답을 찾는 과정이라고 믿습니다. 학부 과정 중 무수히 많은 데이터를 정제하고 모델을 돌려보며, 화려한 알고리즘 이전에 **결측치 하나를 어떻게 처리할지에 대한 논리적인 타당성**이 결과의 질을 좌우한다는 것을 배웠습니다. 

입사 후에는 화려한 AI 모델만 좇기보다, 서비스의 빈틈을 메우고 유저 경험을 1%라도 개선할 수 있는 단단한 데이터 전처리 및 분석 역량을 갖춘 엔지니어로 성장하고 싶습니다.

## 🛠 프로젝트 경험
- **교내 동아리방 예약 시스템 수요 예측 모델링** (2025.03 - 2025.06)
  - **문제 인식:** 시험 기간마다 동아리방 예약 시스템 서버가 다운되거나, 노쇼(No-show)가 발생하는 문제 발생
  - **해결 과정:** 과거 3년 치의 예약 데이터, 교내 학사 일정, 날씨 데이터 등을 크롤링 및 병합하여 특정 시간대 예약 폭주 여부를 예측하는 분류 모델 생성
  - **사용 기술:** Python, scikit-learn, Pandas, GitHub Actions (데이터 수집 자동화)
  - **배운 점:** 모델의 정확도를 높이는 것보다, 지저분한 실제 로그 데이터를 분석 가능한 형태로 가공하는 과정이 전체 일정의 80%를 차지함을 깨달았습니다.
  - **결과물:** [GitHub Repository 링크](https://github.com/minsung-chae/campus-room-prediction)
